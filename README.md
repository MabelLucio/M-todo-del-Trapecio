# Método del trapecio
El método del trapecio se utiliza para resolver nuuméricamente integrales definidas.
## Utilizar el código
Cuenta con una ventana de Tkinter:

![image](https://github.com/user-attachments/assets/642250c3-116b-4552-8903-2b0f40dbc807)

Se ingresan funciones con la variable x, si se necesita multiplicar se utiliza {*}, para elevar se utiliza {**}, por ejemplo:

![image](https://github.com/user-attachments/assets/49bc8e9e-eace-4034-823d-0b22cce6f9ed)

Al dar en _Aceptar_ veremos algo así:

![image](https://github.com/user-attachments/assets/37032a2f-fae3-44ee-960c-b68c6233c57e)

Se puede notar coloreada el aréa del trapecio y circulos rojos que representan el inicio y final de cada una de las divisiones.

Da como resultado también una tabla que muestra el punto y la evaluación de la función en ese punto, junto con el resultado final de la evaluación:

![image](https://github.com/user-attachments/assets/ac31badd-22c7-4455-9528-3dd6ac29ae41)


Además, tiene integradas algunas ventanas de error por si no se ingresan valores válidos:

![image](https://github.com/user-attachments/assets/fc3d3e46-40ef-420d-bd82-469ce48a61d8)

![image](https://github.com/user-attachments/assets/8282b3c0-c208-4b01-b7c0-c39214c1801f)

Muestra como titulo la función ingresada:
